# 📊 Workforce Productivity Analytics

An end-to-end data analytics project that analyzes workforce productivity, operational efficiency, employee performance, quality, overtime, absenteeism, attrition, and labor costs.

The project combines **Python, Pandas, NumPy, Plotly, Jupyter Notebook, MySQL, SQL, and Streamlit** to transform workforce data into actionable business insights through an interactive dashboard.

## 📌 Project Overview

Workforce productivity is influenced by several operational and employee-related factors such as working hours, overtime, output, quality, absenteeism, engagement, and labor costs.

This project analyzes these factors to identify productivity patterns across departments and over time.

The solution follows an end-to-end analytics workflow:

```text
Raw Workforce Data
        ↓
Data Cleaning & Preparation
        ↓
Exploratory Data Analysis
        ↓
Feature Engineering
        ↓
MySQL Database
        ↓
SQL Analysis
        ↓
Interactive Streamlit Dashboard
        ↓
Business Insights
